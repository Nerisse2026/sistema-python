# 🐍 Sistema de Cadastro em Python

Projeto desenvolvido em Python para prática de lógica de programação, entrada e validação de dados e construção de um sistema simples de cadastro.

## 📚 Projetos

### Projeto 1 — Cadastro simples

Sistema básico de cadastro desenvolvido para praticar:

- Entrada de dados com `input()`
- Exibição de informações com `print()`
- Variáveis
- Estruturas condicionais `if/else`
- Estrutura de repetição `while`
- Validação de dados com `isdigit()`
- Conversão de dados para inteiro

### Projeto 2 — Sistema de Cadastro com Menu

Evolução do projeto inicial, com um menu de opções:

1. Cadastrar pessoa
2. Listar cadastros
3. Sair

Neste projeto foram utilizados:

- Listas
- Dicionários
- Estrutura `while`
- Estruturas `if/elif/else`
- Estrutura `for`
- Validação de dados
- `append()`
- `len()`
- Conversão de dados para inteiro
